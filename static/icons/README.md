# PWA Icons Directory

This directory should contain the following icon files for the Progressive Web App:

## Required Icons:
- `favicon.ico` (16x16, 32x32)
- `favicon-16x16.png`
- `favicon-32x32.png` 
- `apple-touch-icon.png` (180x180)
- `safari-pinned-tab.svg`
- `icon-72x72.png`
- `icon-96x96.png`
- `icon-128x128.png`
- `icon-144x144.png`
- `icon-152x152.png`
- `icon-192x192.png`
- `icon-384x384.png`
- `icon-512x512.png`

## Action Icons:
- `add-icon.png` (96x96) - For "New Cheque" shortcut
- `dashboard-icon.png` (96x96) - For "Dashboard" shortcut
- `search-icon.png` (96x96) - For "Search" shortcut
- `checkmark.png` - For notification actions
- `xmark.png` - For notification actions
- `badge-icon.png` - For notification badge
- `notification.png` - Default notification icon
- `offline-image.png` - Fallback for offline images

## Instructions:
1. Create these icons using your app logo/branding
2. Ensure they follow PWA icon guidelines
3. Use transparent backgrounds for better integration
4. Test on different devices and browsers

## Tools for Icon Generation:
- PWA Builder Icon Generator
- Favicon.io
- RealFaviconGenerator.net
